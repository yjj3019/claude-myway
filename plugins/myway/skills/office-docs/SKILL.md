# office-docs

Office 산출물에 일관된 서식을 입히는 디자인 레이어. 파일을 만들고 고치는 메커니즘은 내장 `pptx` / `docx` / `xlsx` 스킬이 맡고, 이 스킬은 무엇을 어떤 색·폰트·레이아웃으로 낼지 정한다.

## 1. 작동 순서

1. **브랜드 프로필 확인.** 아래 순서로 `brand-profile.md`를 찾는다.
   1. 사용자가 이번 요청에서 준 값 또는 파일
   2. 작업 디렉터리의 `brand-profile.md`
   3. `~/.claude/myway/brand-profile.md`
   4. 없으면 `references/brand-profile.default.md`(중립 기본값)
   프로필 양식은 `references/brand-profile.md`에 있다. 값이 부족하면 질문 한 번으로 받는다.
2. **포맷 판별.** 아래 표에서 해당 reference를 읽는다.
3. **메커니즘 로드.** 같은 포맷의 내장 스킬이 있으면 함께 쓴다. 없는 환경(Codex 등)에서는 해당 라이브러리를 직접 쓴다. 생성은 pptx→pptxgenjs, docx→docx-js, xlsx→openpyxl. 편집은 unpack → XML 수정 → repack.
4. **토큰 주입.** 프로필의 값을 코드 상수로 선언해 쓴다. 임의 색·폰트를 쓰지 않는다.
5. **검증.** 산출 후 PDF 변환과 이미지 확인. 텍스트 잘림, 플레이스홀더(lorem, xxxx, 샘플) 잔존이 있으면 고치고 완료를 알린다.

| 포맷 | 읽을 파일 | 함께 쓰는 내장 스킬 |
|---|---|---|
| .pptx 슬라이드 | `references/pptx.md` | `pptx` |
| .docx 제안서·보고서 | `references/docx.md` | `docx` |
| .xlsx 표·데이터·모델 | `references/xlsx.md` | `xlsx` |
| 브랜드 디자인 시스템이 별도 문서로 주어진 발표자료 | `references/branded-deck.md` | `pptx` |
| 챕터 다수의 장문 .docx, 정적 목차·쪽번호 필요 | `references/long-manual.md` (스크립트: `scripts/long-manual/`) | 없음(자체 파이프라인) |

## 2. 우선순위

1. 사용자가 준 기존 템플릿·파일의 서식. 임의 재포맷 금지.
2. 사용자가 준 디자인 시스템 문서와 레퍼런스 이미지.
3. brand-profile 값.
4. 중립 기본값.

충돌하면 앞 순위를 따른다. 사용자가 준 컬러·폰트를 바꾸지 않는다.

## 3. 공통 레이아웃 원칙

- 여백을 넉넉히 둔다. 콘텐츠를 가장자리까지 채우지 않는다.
- 좌측 정렬 기준선을 통일한다. 요소를 임의 위치에 흩지 않는다.
- 제목 > 소제목 > 본문 > 캡션의 크기·굵기·색 대비를 분명히 한다.
- 한 슬라이드·섹션에 핵심 메시지 하나. 정보 과밀을 피한다.
- 지배색은 프로필의 primary 하나. 보조색은 같은 계열로 제한한다. 네온·무지개 팔레트를 쓰지 않는다.
- 밝은 배경이 기본이다.

## 4. 불필요한 장식 금지

별도 요구가 없으면 다음을 넣지 않는다.
- 색상 배지, 1셀 콜아웃 박스, 제목 하단 장식선, 마케팅 문구형 표지
- AI 도구명과 제작 과정 설명
- 서명란. 양식이 요구하거나 사용자가 요청할 때만 만든다.

단색 헤더 행과 표준 표가 기본이다. 사용자 지정 양식에 있는 요소는 유지한다.

## 5. 보안·품질 가드

- API 키, 토큰, `.env` 값, 내부 호스트 자격증명을 본문·메모·숨김 셀·차트 제목에 넣지 않는다. 발견하면 마스킹한다.
- 인용 수치는 표나 각주에 출처와 일자를 적는다. 근거 없는 수치를 만들지 않는다.
- 발표용과 문서 공유용은 텍스트 밀도를 다르게 한다. 발표용은 키워드 중심, 공유용은 문장형.
- 완료 전 시각 검증. xlsx는 수식 에러 0건.

## 6. 완료 전 점검

- [ ] 강조색이 프로필의 primary로 통일됐다
- [ ] 제목·본문 폰트가 프로필 또는 지정 폴백이다
- [ ] 플레이스홀더가 남아 있지 않다
- [ ] 표·차트에 출처와 단위가 있다
- [ ] 시크릿·자격증명이 없다
- [ ] 시각 검증을 마쳤다(잘림·깨짐 없음)
- [ ] 폰트가 설치되지 않아 폴백을 썼다면 그 사실을 한 줄로 알렸다

## 특정 정보가 필요할 때

기관명, 고객명, 호스트명, 주소, 계정, 내부 식별자처럼 특정 대상을 가리키는 값이 필요하면 추측하거나 파일에 미리 적지 않는다. 필요한 항목을 모아 한 번에 질문하고, 받은 답은 이번 산출물과 세션에만 쓴다. 이 스킬의 파일과 저장소에는 되쓰지 않는다. 자격증명과 개인정보는 요청하지 않는다.
