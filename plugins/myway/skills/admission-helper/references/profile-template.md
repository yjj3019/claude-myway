# 학생 프로필 템플릿

**이 파일은 빈 서식이다. 채운 결과를 이 폴더에 저장하지 않는다.** 스킬은 공유되는 패키지이므로 개인 데이터가 들어가면 그대로 외부로 나간다. 채워진 프로필은 사용자의 작업 공간에 두고, 분석할 때마다 대화나 사용자 파일에서 읽어 온다.

아래 항목이 비어 있으면 추정하지 말고 사용자에게 묻는다.

---

## 1. 지원 자격 — 가장 먼저 확정할 것

| 항목 | 값 | 왜 필요한가 |
|---|---|---|
| 고교 소재 권역 | | 지역인재 자격의 유일한 기준 |
| 읍·면 소재 여부 | | 농어촌학생전형 자격 |
| 졸업 구분 | 졸업예정 / N년 졸업 | 반영 기간과 지원 가능 전형이 달라짐 |
| 고교 유형 | 일반고 / 특목고 / 자율고 / 특성화고 | 전형별로 지원 제한이 걸림 |
| 기회균형 해당 여부 | | 기초·차상위·한부모·국가보훈·다자녀 등 |
| 통학 가능 범위 | | 기숙사·자취 가능 여부에 따라 지역 범위가 결정됨 |

지역인재 권역 구분과 해당 여부는 해당 연도 요강에서 확인한다. 수도권 고교가 지역인재에 해당하지 않는 경우가 일반적이다. 반면 지역균형·학교장추천은 출신 지역을 따지지 않는다.

| 과학 | | | | | |

미이수 교과는 "—"로 표기한다. 1학년만 이수한 교과는 그 사실을 적어 둔다 — 반영 대상에서 빠지거나 가중치가 달라질 수 있다.

## 3. 교과 조합별 등급

대학마다 반영 조합이 다르므로 미리 계산해 두면 대입이 빠르다.

| 조합 | 평균 | 1학년 | 2학년 | 3학년 |
|---|---|---|---|---|
| 전교과(예체능 제외) | | | | |
| 국영수사과 | | | | |
| 국영수사 | | | | |
| 국영수 | | | | |
| 국영사 | | | | |
| 국영 | | | | |
| 영수과 | | | | |

**기준선**을 하나 정한다. 보통 전교과(예체능 제외)를 쓴다. 모든 대학 분석에서 이 값과의 차이로 유불리를 표시한다.

**주의** 사설 분석 리포트의 "전교과" 값은 예체능 성취도를 임의 등급으로 환산해 포함하는 경우가 있다. 대학 산출식과 다르므로 기준선으로 쓰지 않는다.
