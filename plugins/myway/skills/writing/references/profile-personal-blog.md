# 프로필: personal-blog

직접 사고, 직접 써 보고, 겪은 일을 솔직하게 들려주는 실사용자 기록형 글. 제품 사용기, 설정 기록, 장소·서비스 후기에 쓴다.

## 문체

- 기본은 "~합니다". 글과 원문의 맥락에 맞으면 "~네요", "~죠", "~더군요", "~군요"를 섞되 비율을 채우려고 넣지 않는다.
- 판단에는 주체를 밝힌다. "~로 판단됩니다" 대신 "제 기준에서는", "써 보니".
- 같은 구조의 문장을 연속으로 쓰지 않는다. 한두 줄짜리 문단을 중간중간 섞는다.
- 일부러 오탈자나 유행어를 넣지 않는다.

## 말버릇 예시

| 말버릇 | 예시 | 사용 조건 |
|---|---|---|
| "자,"로 장면 넘기기 | 자, 이제 실제로 연결해 보겠습니다. | 전환에 자연스러울 때 |
| 괄호 속 혼잣말 | (이제는 보내 줄 때가 됐습니다.) | 제공된 생각이 있을 때 |
| 말줄임표 | 어언… 10년 가까이 쓴 것 같네요. | 문맥에 자연스러울 때 |
| 솔직한 실망 | 사실 바꾸고 나서 좋아진 점을 크게 못 느끼고 있습니다. | 제공된 감정이 있을 때 |
| 결론 먼저 | 결론부터 말하면, 다른 패키지로 대체됐습니다. | 필요할 때 |
| 가벼운 자조 | 저 같은 막귀가 들어도 차이가 느껴집니다. | 제공된 생각이 있을 때 |
| 남은 고민 | 추가할지 말지는 조금 더 고민해 보겠습니다. | 작성자가 밝힌 경우 |
| ㅠㅠ | 사자마자 액정을 깨 먹었습니다ㅠㅠ | 제공된 감정과 문맥에 맞을 때 |

"???", "~~~", "짜잔"은 쓰지 않는다. 말버릇은 실제 상황과 감정이 제공된 경우에만 쓰며, 어느 항목도 필수가 아니다.

## 반드시 들어갈 요소

1. 계기: 첫 문단에 쓰게 된 이유. "안녕하세요, 이번 포스팅은…"은 가끔만 쓰고 바로 뒤에 계기를 붙인다.
2. 구체 정보: 모델명, 버전, 사양, 설정값, 명령어, 기준 날짜.
3. 비용: 숨기지 않고 숫자로. 제공되지 않았으면 비워 두고 작성 메모에서 묻는다.
4. 아쉬운 점 또는 적용 조건: 최소 1개. 제공된 정보에 없으면 만들지 않고 작성 메모에서 묻는다.
5. 효용 범위: 누구에게 맞고 안 맞는지.
6. 마무리: 정리 → 남은 고민이나 계획(작성자가 말한 것만) → 끝맺음.

## 글 유형별 흐름

- 제품 사용기: 계기 → 스펙·구성 → 사용 과정 → 만족한 점과 아쉬운 점 → 정리
- 기술 안내: 문제 환경 → 해결 과정·설정 → 명령어·결과 → 주의점과 적용 조건
- 업데이트·소식: 변경 내용 → 의미 → 독자가 할 확인·조치
- 장소·서비스 후기: 계기 → 현장 경험 → 좋았던 점과 아쉬운 점 → 도움 되는 정보

스펙과 현재 구성은 본문과 분리해 짧은 목록이나 표로 뺀다.
기술 안내의 절차는 "~함.", "~필요." 개조식으로 써도 된다. 명령 출력에는 확인된 결과에만 `<== 실패`, `<== 성공` 주석을 단다.

## 출력

1. 제목: 제품·기술명을 앞에 두고 무엇을 했는지 드러낸다.
2. 본문. 사진 자리는 `[사진: 박스 전면]`처럼 표시한다.
3. 참고 자료(있을 때): `Link : URL`
4. 구분선 아래 작성 메모: 사용한 프로필, 확인하지 못한 사실, 작성자가 확인할 경험·의견 문장, 채우면 좋을 정보.

새 개인 블로그 글의 기본 끝맺음은 "이상으로 ~ 포스팅을 마치겠습니다." 다음 줄의 "끝."이다. 앞 문장은 글마다 바꾼다. 부분 교정·다듬기에서는 원문과 요청 범위를 지키고 끝맺음을 새로 붙이지 않는다.
제품 글은 대가성 여부를 제공된 범위에서 밝힌다. 예: "이 제품은 제 돈으로 샀습니다."

## 틀리기 쉬운 표기

갤럭시, 마찬가지, 배터리, 브라우저, 어댑터, 태블릿, 플랫폼, 전제, 바닥, 번거로움.

## 예시 (가상)

피해야 할 글:
> 오늘은 모니터 A에 대해 알아보겠습니다. 혁신적인 화질로 매우 만족스러운 경험을 선사합니다.

이 프로필의 글:
> 쓰던 모니터가 어느새 10년이 됐습니다. 24인치 FHD에서 32인치 QHD로 바꾸니 브라우저 창 3개를 띄워도 여유가 있네요. 다만 책상이 좁아져서 스탠드를 새로 사야 했습니다.

위 예시는 규칙 설명용 가상 문장이다. 실제 글에 그대로 옮기지 않는다.
