# 편집 강도와 작업 흐름

수정 범위와 표현 방식을 구분한다. 아래 강도는 바꿀 수 있는 범위다. "자연스럽게", "짧게" 같은 요청은 그 범위 안에서 적용한다.

## 강도

| 강도 | 범위 | 유지할 것 |
|---|---|---|
| 교정 | 맞춤법, 띄어쓰기, 문장부호만 수정 | 어휘, 문장 순서, 구조. "오탈자만"처럼 더 좁은 지시는 그 범위만 따른다 |
| 다듬기 | 어색한 문장과 연결, 불필요한 반복을 필요한 만큼 수정 | 원래 문체, 제목·절·표·문단 순서, 분량 |
| 재작성 | 명시한 범위에서 문장·문단·구성 변경 | 사실, 출처, 부정, 조건, 확실성 수준 |

- 강도를 지정하지 않으면 다듬기로 최소한만 수정한다.
- "검토만"이면 의견만 제공한다.
- 신규 작성, 요약, 지정 양식 요청은 해당 요청을 따른다. 편집 강도 때문에 작업을 취소하지 않는다.
- 재작성이라도 기술 수정이나 새 사실 추가까지 허용하는 것은 아니다.
- 교정과 부분 수정에서는 요청한 수정문만 출력한다. 제목, 도입, 작성 메모를 관례적으로 추가하지 않는다.

## 목적별 표현 방식

| 방식 | 용도 | 하는 일 |
|---|---|---|
| 자연스럽게 다듬기 | 블로그, 개인 글 | 흐름과 어조 정리 |
| AI 티 줄이기 | 상투적 표현이 많은 글 | 상투 표현 축소, 핵심 의미 유지 |
| 짧고 직접적으로 재작성 | 기술 문서, 가이드, 업무 메모 | 한 문장에 핵심 정보, 행동 주체와 조건 명시 |

모든 글에 같은 방식을 강요하지 않는다.

## 비교 절차 (필요할 때만)

1. 기준 초안을 만든다. 원문은 비교용으로 그대로 둔다.
2. 목적에 맞는 방식으로 후보를 만든다.
3. 다음 네 항목으로 비교한다: 자연스러움, AI 느낌 감소, 명확성·직설성, 원래 의도 유지.
4. 글 목적에 맞는 방식을 고르거나 둘을 조합한다.
5. 의미가 왜곡됐는지 확인한다. 최종 검수는 작성자가 한다.

사용자가 한 가지 결과만 요청하면 비교표를 출력하지 않고 고른 결과만 낸다.

## 수정 후 대조

1. 이름, 수치·단위, 날짜, 부정·조건·예외, 인용·출처, 기술 문자열의 추가·누락·의미 변화를 원문과 대조한다.
2. 내용을 합치면서 항목, 순서, 동시성, 조건이 사라지지 않았는지 읽어 본다.
3. 요약 요청이면 세부사항을 줄이되 결론을 바꾸는 부정·조건·예외와 핵심 근거는 남긴다.
4. 원문의 모순은 임의로 하나를 선택하지 않는다. 결론에 영향을 주면 질문하거나 작성 메모로 분리한다.
5. 표현 점검에서 걸린 단어는 문맥을 보고 판단한다. 직접 인용, 고유명사, 작성자가 고른 표현, 정확한 기술 용어, 의미 있는 반복은 보존한다.
6. 미확인 항목만 작성 메모에 남기고 관례적인 검수 요청 문장은 덧붙이지 않는다.

## 문서 산출물 서식

- 별도 양식이 없으면 색상 배지, 1셀 콜아웃 박스, 영문 마케팅톤 표지를 추가하지 않는다. 사용자 지정 양식과 정보 전달에 필요한 색상·표시는 유지한다.
- 제공된 표준 서식이 있으면 따른다. 없으면 단색 헤더와 표준 표를 기본으로 한다. 서명란은 양식이 요구하거나 사용자가 요청할 때만 만든다.
- 제작 과정 설명은 생략한다. 주제나 재현 조건에 필요한 AI 제품명·모델명은 정확히 쓴다.
- 단위와 숫자는 평문으로 쓴다(180°C, 10%). 수식 표기는 수학·과학 수식에만 쓴다.
