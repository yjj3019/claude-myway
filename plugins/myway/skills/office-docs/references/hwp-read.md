# HWP/HWPX 원문 읽기

사용자가 제공하거나 공개적으로 접근할 수 있는 한글 문서를 읽는 선택적 경로다. 원본의 내용과 요청한 사용 범위를 따른다. 변환 결과는 원문을 찾고 읽기 위한 보조 자료이며, 원본의 쪽·표·수식·서식을 완전히 재현했다는 증거가 아니다.

## 읽기

1. 사용자 환경에 이미 설치된 HWP/HWPX 읽기 도구가 있으면 그 도구를 쓸 수 있다. `kordoc`이 이미 있으면 버전을 확인하고 로컬 읽기 기능을 선택할 수 있다. 시험한 조합은 Windows·Node 24·kordoc 4.24.13의 HWP/HWPX 읽기다. 다른 버전·환경은 별도 확인한다. 없으면 자동 설치·업데이트하거나 MCP 설정을 변경하지 않는다. 접근 가능한 다른 원본이나 변환본을 요청한다.
2. `kordoc` 사용 시 `KORDOC_OFFLINE=1`을 해당 실행에 설정하고 `--format json --no-images`로 텍스트·블록·표·메타데이터·경고를 확인한다. 이 설정은 프로그램의 네트워크 경로에 대한 제한이며 운영체제 샌드박스를 뜻하지 않는다. OCR은 별도 기능·모델과 검증이 필요하며 이 읽기 경로에서 자동으로 준비하지 않는다.
3. 원본을 수정·덮어쓰지 않는다. 결과를 파일로 저장할 필요가 있으면 사용자가 허용한 작업 공간의 새 이름을 사용하고 기존 파일을 덮어쓰지 않는다. 문서 내용과 개인정보를 스킬 폴더·저장소·공유 로그에 넣지 않는다.
4. 결과의 `success`와 `warnings`를 확인한다. 실패·부분 추출·미지원 요소·표 누락이나 판독 불가 항목은 숨기지 않고 확인 필요로 남긴다. 경고가 없다는 사실만으로 전체 내용을 정확히 읽었다고 판정하지 않는다.

## 출처와 페이지 확인

- 원본 문서명·버전·확인 시점을 기록하고, 주요 주장과 수치·부정·조건·표의 행과 열을 원본이나 신뢰할 수 있는 대응 렌더와 대조한다. 자동 추출 결과만으로 중요한 사실을 확정하지 않는다.
- `metadata.pageMode`가 `section`이면 추출의 쪽 숫자는 실제 페이지가 아니라 섹션 기준일 수 있다. `layout`이어도 원본 화면의 페이지와 일치한다고 가정하지 않는다. 공개 HWP 및 HWPX 각 1건의 대응 PDF 비교에서도 쪽 수가 달랐으며 두 파일의 판본 일치 여부는 확인하지 못했다.
- 인용 페이지는 원본 또는 판본이 확인된 렌더에서 직접 검증한 위치만 쓴다. 확인할 수 없으면 페이지를 추정하지 않고 `쪽 미확인`으로 표시한다. 모집요강의 자격·반영 비율·모집인원 등 판정에 필요한 항목을 원문에서 확인할 수 없으면 해당 판정을 보류한다.

이 경로는 읽기에 한정한다. HWPX 생성·패치·원본 서식 보존·스캔 OCR은 검증된 범위가 아니며, 사용자가 별도 요청하더라도 해당 작업에 맞는 도구와 독립 검증을 먼저 확인한다.
